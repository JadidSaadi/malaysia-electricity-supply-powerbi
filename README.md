# Malaysia Electricity Supply Dashboard — Power BI

## Overview

A Power BI data analytics project examining Malaysia's electricity supply trends from 2018 to 2024.

The dashboard visualises electricity supply patterns and provides key summary statistics including maximum, minimum, average, and total electricity supply.

## Tools & Technologies

- Microsoft Power BI
- DAX
- Data Visualisation
- Microsoft Excel
- Quantitative Data Analysis

## Key Insights

- Maximum electricity supply: 65.59K million kWh
- Minimum electricity supply: 46.74K million kWh
- Average electricity supply: 56.69K million kWh
- Total electricity supply: 4.42M million kWh

## Dashboard

The dashboard includes:

- Electricity supply trend from 2018–2024
- Maximum electricity supply
- Minimum electricity supply
- Average electricity supply
- Total electricity supply

## Project Purpose

This project demonstrates practical skills in data analysis, Power BI dashboard development, DAX measures, and visualisation of energy-related data.
